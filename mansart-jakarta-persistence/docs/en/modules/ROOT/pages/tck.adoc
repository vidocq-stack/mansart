= TCK
:description: Jakarta Persistence 3.2 TCK conformance status

== Overview

Mansart Persistence targets 100% conformance with the Jakarta Persistence 3.2 TCK.

== TCK Configuration

The TCK runner is configured in `mansart-jakarta-persistence/mansart-persistence-tck/`:

* Maven profile: `tck-run` for H2 in-memory tests
* Maven profile: `tck-pg` for PostgreSQL tests (requires Docker)
* Maven profile: `tck-sig` for Signature tests
* Test framework: TestNG + Arquillian + Vauban (CDI Lite)

== Running the TCK

=== Quick Smoke Tests

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn test
----

=== Full TCK on H2

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn -Ptck-run test -DfailIfNoTests=false
----

=== TCK on PostgreSQL

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn -Ptck-run,tck-pg test -DfailIfNoTests=false
----
