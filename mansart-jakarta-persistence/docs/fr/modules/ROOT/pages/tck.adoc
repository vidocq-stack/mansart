= TCK
:description: État de conformité Jakarta Persistence 3.2 TCK

== Aperçu

Mansart Persistence vise une conformité à 100% avec le TCK Jakarta Persistence 3.2.

== Configuration TCK

L'exécuteur TCK est configuré dans `mansart-jakarta-persistence/mansart-persistence-tck/` :

* Profil Maven : `tck-run` pour les tests H2 en mémoire
* Profil Maven : `tck-pg` pour les tests PostgreSQL (nécessite Docker)
* Profil Maven : `tck-sig` pour les tests de signature
* Framework de test : TestNG + Arquillian + Vauban (CDI Lite)

== Exécuter le TCK

=== Tests Smoke rapides

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn test
----

=== TCK complet sur H2

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn -Ptck-run test -DfailIfNoTests=false
----

=== TCK sur PostgreSQL

[source,bash]
----
cd mansart-jakarta-persistence/mansart-persistence-tck
mvn -Ptck-run,tck-pg test -DfailIfNoTests=false
----

== Blocages

1. **EntityGraph** - API metamodel complexe Jakarta Persistence 3.2 (Graph, ManagedType, AttributeNode, Subgraph)
2. **StoredProcedureQuery** - 39 erreurs restantes, nécessite une implémentation supplémentaire
3. **Annotations** - @AssociationOverride et annotations connexes
4. **Intégration des transactions** - Intégration complète avec Mansart Transactions
