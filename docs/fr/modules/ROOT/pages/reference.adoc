:description: Artefacts Maven, dialectes, propriétés MicroProfile Config.

[CAUTION]
Mansart est en conception. Les artefacts ci-dessous décrivent la cible — voir `mansart/PLAN.md` à la racine du repo pour l'état d'avancement réel.

== Artefacts Maven

[cols="1,3"]
|===
| Artefact | Rôle

| `io.vidocq.mansart:mansart-jakarta-data:0.1.0-SNAPSHOT`
| Implémentation Jakarta Data 1.0

| `io.vidocq.mansart:mansart-persistence:0.1.0-SNAPSHOT`
| Implémentation Jakarta Persistence 3.2 *(en plan)*

| `io.vidocq.mansart:mansart-pool:0.1.0-SNAPSHOT`
| Pool JDBC virtual-threads

| `io.vidocq.mansart:mansart-transactions:0.1.0-SNAPSHOT`
| `UserTransaction` + `@Transactional`
|===

* Java 25, Maven 4.0.0-rc-5.
* Jakarta Data 1.0, Jakarta Persistence 3.2 *(en plan)*.
* Virtual Threads pour l'exécution.
