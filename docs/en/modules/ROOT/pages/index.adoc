= Mansart
:description: Jakarta Data 1.0 + Jakarta Persistence 3.2, JDBC dialects, virtual threads.

[.lead]
Mansart is the Jakarta Data 1.0 and Jakarta Persistence 3.2 implementation of the Vidocq ecosystem — repositories, pagination, query methods, pluggable JDBC dialects, no heavy ORM. Build the persistence layer the way Versailles was built: durable modules, carefully assembled.

[CAUTION]
====
Mansart is in design. The Jakarta Data 1.0 SPI (`mansart-jakarta-data`) is being stabilized; `mansart-persistence` (JPA 3.2) is still on the drawing board (see `mansart/PLAN.md` at the repo root). This documentation describes the target API — `[TODO]` markers flag what has not been delivered yet.
====

== Why?

Jules Hardouin-Mansart (1646-1708), First Architect to the King, designer of the Hall of Mirrors at Versailles, the Invalides dome, the Place Vendôme. He led the Royal Academy of Architecture, codified the orders, negotiated with masons and sculptors. The work has stood for three centuries because every piece was designed to fit into the next, and decoration was never confused with structure.

The Mansart persistence layer applies the same separation. `mansart-jakarta-data` is the public API (repositories, query methods, pagination). `mansart-persistence` implements JPA 3.2 and is consumed by `mansart-jakarta-data` on the SQL backend side. `mansart-pool` handles the JDBC connection pool. `mansart-transactions` exposes `UserTransaction` and `@Transactional`. Four modules, each with a clear contract.

== At a glance

* **Jakarta Data 1.0** — `@Repository`, `Page`, `PageRequest`, `Sort`, query methods (`findByXxx`, `@Query`), generic CRUD.
* **Jakarta Persistence 3.2** *(planned)* — `EntityManager`, JPQL, Criteria, static metamodel generated by APT.
* **Pluggable JDBC dialects** — H2 (reference for tests), PostgreSQL (production target), more in the backlog.
* **Virtual Threads** for query execution — no platform pool.
* **TDD + Arquillian** for the TCK harness (Jakarta Data 1.0 TCK when available).
* **No hidden auto-commit**, no `EntityManager` proxy, no runtime entity scan.
