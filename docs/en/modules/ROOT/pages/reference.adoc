:description: Maven artefacts, dialects, MicroProfile Config properties.

[CAUTION]
Mansart is in design. The artefacts below describe the target — see `mansart/PLAN.md` at the repo root for actual progress.

== Maven artefacts

[cols="1,3"]
|===
| Artefact | Role

| `io.vidocq.mansart:mansart-jakarta-data:0.1.0-SNAPSHOT`
| Jakarta Data 1.0 implementation

| `io.vidocq.mansart:mansart-persistence:0.1.0-SNAPSHOT`
| Jakarta Persistence 3.2 implementation *(planned)*

| `io.vidocq.mansart:mansart-pool:0.1.0-SNAPSHOT`
| Virtual-thread JDBC pool

| `io.vidocq.mansart:mansart-transactions:0.1.0-SNAPSHOT`
| `UserTransaction` + `@Transactional`
|===

* Java 25, Maven 4.0.0-rc-5.
* Jakarta Data 1.0, Jakarta Persistence 3.2 *(planned)*.
* Virtual Threads for execution.
